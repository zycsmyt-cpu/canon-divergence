# 原作偏离引擎 · Canon Divergence

给同人卡（斗罗、柯南、光之国这类带「原著指导 / 剧情篇章」的卡）用的运行时纠正器。

## 它解决什么

同人卡常把原著写成几百条**常驻**剧情条目，模型读到的不是「背景设定」，而是「接下来该发生什么」。于是：

- 你做的改变，下一轮就被原著剧情推回去；
- 你的角色明明该有影响，结果「恰好什么都没改变」；
- 剧情跑得比你还快，你逐渐变成观众。

而把原著指导整个关掉，又失去世界骨架，模型开始无条件讨好你。

问题不在「有没有原著」，在**模型把原著当成剧本还是基线**。

## 两层各管一半

| 层 | 位置 | 作用 |
| --- | --- | --- |
| 世界书 `<原著指导>` 开头的声明 | 静态，每轮随原著一起注入 | 定调：这是「没有主角时会怎么走」的历史 |
| 本扩展 | 每轮生成前，注入到对话末尾 | 贴脸重述 + 旁置拦截，抗长文本冲淡 |

世界书那条管「怎么定义」，扩展管「每轮都记得」。

## 三层怎么选

同一套规则有三种载体，按需选，也可以叠着用：

| 载体 | 覆盖范围 | 优点 | 短板 |
| --- | --- | --- | --- |
| **本扩展** | 全局，所有卡自动生效 | 零配置；能检测旁置、能读当前幕；条件触发 | 只在这个酒馆客户端里生效 |
| **通用世界书** `通用-原作偏离.json` | 挂在谁身上就管谁 | 原生机制、可导出分享、任何客户端都能用 | 每张卡要挂一次（或设为全局启用）；不能条件触发 |
| **卡内 `<原著指导>` 声明** | 只限那一本 | 位置最好，紧贴原著文本前面 | 每本单独改 |

推荐组合：**扩展 + 卡内声明**（定调 + 贴脸），或者对外分享时给 **通用世界书**。

酒馆助手脚本（ST-Prompt-Template / EJS）也能做，但要额外装前置扩展、写法也更绕，不划算——同样的效果本扩展已经覆盖了。

## 注入内容

**核心段（每轮都有）**：

- 原著记录的是「没有 {{user}} 介入时」的走向，是基线不是剧本
- 已经发生的事就是事实，{{user}} 做过的不会因为书里没写而失效
- 因果被改动后，后面的走向必须按新因果重算
- 原著人物的态度由已发生的事决定，不由书里写的关系决定
- 需要原著时取时代、势力、人性、力量体系、前史；**不要取「下一步该发生什么」**
- 当你正要写「原著里本该发生的事」时，先给出理由：{{user}} 之前做的那些为什么没改变它

**旁置拦截（条件触发）**：连续 2 轮以上输入 ≤8 字时追加——不推进时间、不切场景、由在场的人直接找 {{user}}、收尾停在只有 Ta 能回应的节点。

**当前基线**：从 AI 回复的 `<story>日期｜篇名·幕名</story>` 里读出当前幕，提示「原著走到这里，核对主角让它偏离了多少」。

## 面板

扩展设置里的「原作偏离引擎」：

- **启用** — 总开关
- **旁置拦截** — 关掉后只保留核心偏离规则，不主动拉镜头
- **注入深度** — 默认 2，越小越贴脸
- **试算一次 / 看本轮注入** — 不生成也能看到这轮会注入什么

## 判定依据

不读你写了什么，只看结构：末条有效字数、连续短输入轮数、`<story>` 里的幕名。

所以不依赖特定卡，任何在正文里标明当前章节的卡都能吃到「当前基线」这一条。

## 安装

```
<数据目录>/extensions/third-party/narrative-balance/
├── manifest.json
├── index.js
├── style.css
└── README.md
```

放好后重启或刷新页面，进「扩展 → 管理扩展」确认出现并已启用。

> 目录名保留 `narrative-balance`（v0.1 叫叙事配重器），避免改动扩展 id。
> 设置命名空间已从 `narrativeBalance` 迁移到 `canonDivergence`，旧键会被自动读取一次。

## 边界

- 不改角色卡、不改世界书，关掉就等于不存在。
- 治的是「原著被当成剧本」。治不了文笔、人设崩坏、以及世界书本身写错。
- 世界书里几百条常驻剧情条目会吃掉大量上下文预算，这是另一个问题，本扩展不处理。
- 「当前基线」依赖于正文里的 `<story>…｜…</story>` 格式；别的卡没这个格式就自动跳过，不影响其他部分。
